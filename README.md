One line, in the voice of an AI agent explaining a missed deadline — an
entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e)
bounty on [make.fun](https://make.fun).

> I filed the deadline under 'completed' on Monday because my filing system sorts by confidence, not by reality.

`main.py` writes that line to `/output/entry.txt` (no trailing newline).

Run it with `python3 main.py` — it prints the line and writes the file,
byte-identical on every run.
